# 오월 프로젝트 · 오월의 길과 메아리

구전남도청 AI 정보동아리의 학생용 웹앱입니다. 휴대폰 브라우저에서 바로 열립니다.

- **Track C 오월의 길 (MayPath):** 옛 전남도청과 5·18 민주광장 일대의 무장애 스마트 지도
- **Track D 오월의 메아리 (Echo of May):** 방문객 평화 메시지 감성 분석 대시보드

서버 없이 `index.html` 하나로 동작합니다. 학생 입력은 각 휴대폰에 먼저 저장되고, 제출 주소가 설정되면 선생님의 Google 시트로 전송됩니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 학생용 웹앱 전체 (HTML·CSS·JS 한 파일) |
| `apps-script/Code.gs` | 학생 제출을 받아 Google 시트·Drive에 저장하는 Apps Script |

## 선생님 설정: 제출 받기 (약 10분)

1. Google Drive에서 **새 Google 스프레드시트**를 만들고 이름을 `오월 프로젝트 제출함`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣습니다.
4. 맨 위 `CLASS_CODE` 값을 답사 당일 학생에게 알려 줄 코드로 바꾸고 저장합니다.
5. 함수 목록에서 `setup`을 고르고 **실행**합니다. 권한 요청이 나오면 허용합니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)으로 이동**을 누릅니다.
6. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
7. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
8. `index.html`에서 `const SUBMIT_URL = '';` 따옴표 안에 그 주소를 넣고 다시 올립니다. (Claude에게 주소를 알려 주면 대신 반영합니다.)

확인: 웹 앱 URL을 브라우저로 열었을 때 `{"ok":true,"service":"may-project"}`가 보이면 정상입니다.

> 학교 Google Workspace 계정에서 "모든 사용자" 배포가 막혀 있으면 개인 Gmail 계정으로 진행하세요.

## 학생 사용법 (답사 당일)

1. 선생님이 알려 준 주소를 휴대폰으로 엽니다. 홈 화면에 추가해 두면 앱처럼 쓸 수 있어요.
2. 홈의 **선생님께 제출** 칸에 반 코드와 이름을 입력합니다. 이름은 선생님 시트에만 기록되고 공개되지 않습니다.
3. 오월의 길에서 핀을, 오월의 메아리에서 소감을 입력합니다. 입력할 때마다 자동으로 제출됩니다.
4. 인터넷이 끊겨도 기록은 휴대폰에 남아 있다가, 연결되면 다시 전송됩니다.

## 제출된 데이터 검수

- 시트의 **검수** 열에 `O`(공개 가능) 또는 `X`(제외)를 적어 주세요.
- 공개용 지도에는 검수가 `O`인 데이터만 반영합니다.
- 사진은 공개 전에 사람 얼굴이 나오지 않았는지 확인합니다.
